## Planning Process

### Weekly Planning

1. Review [Active Tasks](tasks.md)
2. Update progress in [Implementation Plan](implementation-plan.md)
3. Adjust priorities based on blockers

### Monthly Planning

1. Review [Strategic Plan](strategic-plan.md)
2. Update roadmap timelines
3. Archive completed phases
4. Plan next month's priorities

### Release Planning

1. Check all tests passing
2. Update documentation
3. Create release notes
4. Plan next release cycle
