# Agent skills

The current beta does not expose a managed agent-skill command. Check the
top-level commands in your installed CLI before following guidance written for a
different version:

```text
anvil --help
```

If `skill` is not listed, the capability is not available. Do not copy files
from a source repository or an internal setup guide.

Use [AI-assisted write protection](../guides/agent-harness.md) for the
maintained client workflow.
