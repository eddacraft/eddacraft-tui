# Tutorials

Complete [install and get first value](../quickstart.md) before choosing a
tutorial.

| Goal                           | Tutorial                                           | Time       |
| ------------------------------ | -------------------------------------------------- | ---------- |
| Prove a finding and safe fix   | [Ten-minute protection tutorial](../first-gate.md) | 10 minutes |
| Prove the save-time loop       | [Catch a saved change](first-save-caught.md)       | 10 minutes |
| Check a Rust project           | [Rust project tutorial](rust-project.md)           | 10 minutes |
| Define dependency direction    | [Architecture tutorial](architecture.md)           | 20 minutes |
| Compare architecture over time | [Drift tutorial](drift.md)                         | 15 minutes |
| Install and test a policy pack | [Policy tutorial](policies.md)                     | 20 minutes |

Each tutorial states its prerequisites and expected result. Tutorials that
create temporary files include an explicit cleanup step; read it before
beginning.
