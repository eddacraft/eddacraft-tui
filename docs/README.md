## Discovery

Generated documentation indexes are the canonical navigation surface:

- [`indexes/README.md`](indexes/README.md) — landing page linking the five
  generated indexes.
- [By type](indexes/by-type.md) · [By authority](indexes/by-authority.md) ·
  [By owner](indexes/by-owner.md) · [By status](indexes/by-status.md) ·
  [By tag](indexes/by-tag.md)

The indexes are generated by `pnpm docs:index` from document-local metadata — do
not edit them by hand. Add a doc by giving it the governance metadata table
described in
[guides/documentation-governance.md](guides/documentation-governance.md#metadata-convention)
and re-running `pnpm docs:index`.

## Top-level layout

```
docs/
├── architecture/   # Architecture deep-dives and as-built docs
├── guides/         # Developer how-to guides
├── runbooks/       # Operational playbooks
├── policies/       # Operational policies and documented limits
├── specs/          # Live technical specifications
├── public/         # Public-facing documentation (separate authority surface)
├── indexes/        # Generated discovery surfaces (do not edit by hand)
└── archive/        # Historical documents (read-only reference)
```

`testing/`, `reviews/`, `strategy/`, `vision/`, `observability/`, `internal/`,
`plans/`, `marketing/`, `governance/` are also present today; the generated
indexes are authoritative for the full per-document set.

## Planning Documents

All active planning lives at [`plans/`](../plans/). Start at
[`plans/index.aps.md`](../plans/index.aps.md) for the module overview.

## Public Documentation

User-facing documentation in [`public/`](public/) is a separate authority
surface — see the public docs site for its discovery layer; do not link from
this internal surface into public docs for general navigation.

## Archive

[`archive/`](archive/) contains historical documents preserved for reference.
Read-only — do not edit archived documents. Point-in-time review writeups should
move to [`archive/reviews/`](archive/reviews/) once their follow-up work is
merged or superseded.
