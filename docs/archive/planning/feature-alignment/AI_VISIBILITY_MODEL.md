# AI_VISIBILITY_MODEL — Cascading Maturity

1. AI-aware

- Export constraints (patterns/boundaries/anti-patterns) in machine-readable
  form.

2. AI-reflective

- Export structured feedback/warnings feed (same schema as humans see).

3. AI-guiding

- Provide authoritative constraints during generation (prompt injection/IDE
  integration), while Anvil remains deterministic.

4. AI-collaborative (later)

- Constrained feedback loops (AI proposes, Anvil evaluates, human decides).

Hard boundary:

- AI never approves exceptions/risk acceptance.
