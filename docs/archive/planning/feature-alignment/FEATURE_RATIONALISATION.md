# FEATURE_RATIONALISATION — Keep / Reshape / Defer

## Keep (foundation)

- Deterministic runner + structured results
- CLI orchestration for checks
- Dependency analysis primitives

## Reshape (right idea, wrong positioning)

- Plans/APS: optional accelerator, never required for first value
- OPA/policies: internal engine + advanced extension; surface should be
  patterns/boundaries/anti-patterns
- “Gates”: supporting signals; not the headline

## Defer (later)

- Full drift dashboards
- Deep integrations beyond PR/CI mirroring
- Advanced architecture modelling beyond init baseline
- AI-collaborative refactors/auto-fixes by default
