# V1_SCOPE — “Save-time Trust”

## Goal

Give individual developers confidence to merge AI-generated code without
introducing architectural drift or toxic patterns.

## Must-have

- Save-time warnings (IDE/CLI)
- Architecture baseline inference + NEW edge detection (acknowledge legacy
  drift)
- AI anti-pattern catalogue v1 (high-confidence warnings)
- Actionable warnings (explain + suggest)
- Explicit suppressions with inline note + provenance
- PR/CI mirroring as fail-safe (same semantics, later delivery)

## Out of scope (defer)

- Plans/APS as a prerequisite
- Hard-blocking by default
- Auto-fix as default
- Perfect journey mapping
- Org dashboards
