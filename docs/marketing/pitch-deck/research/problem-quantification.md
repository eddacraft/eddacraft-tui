# Problem Quantification: The Ungoverned AI Code Crisis

## Executive Summary

AI-generated code is shipping at unprecedented volumes with measurable quality
degradation, security vulnerabilities, and architectural erosion. The governance
gap between AI code generation and production deployment is quantifiable,
growing, and increasingly expensive.

## The Governance Gap (Summary)

```
AI Code Generation          →  46% of all code
Governance at Generation    →  0% (no tools enforce at file save)
Review Before Commit        →  <50% of developers review AI output
Post-commit Scanning        →  Catches defects after the damage is done
Architecture Drift          →  Invisible until crisis
Authorship Attribution      →  Non-existent in production codebases
```

**The gap**: Between AI generation and production deployment, there is no
governance layer. Anvil fills this gap.
