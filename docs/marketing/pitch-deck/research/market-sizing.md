# Market Sizing: Anvil by EddaCraft

## Executive Summary

Anvil operates at the intersection of three expanding markets: AI code tools, application security testing, and AI governance platforms. The combined opportunity is large and accelerating, driven by AI-generated code volumes, regulatory pressure, and enterprise demand for governance infrastructure.

## SAM -- Serviceable Addressable Market

Anvil's serviceable market is engineering teams that:
1. Use AI coding assistants (generating code that needs governance)
2. Have compliance or quality requirements (regulatory, enterprise policy, or architectural standards)
3. Operate at sufficient scale to warrant tooling investment (>20 developers)

### Key Sizing Inputs

| Metric | Value | Source |
|--------|-------|--------|
| Developers using AI tools | 84% of all developers | Stack Overflow 2025 Survey |
| Daily AI tool usage | 51% of professional developers | Stack Overflow 2025 Survey |
| Fortune 100 adoption of Copilot | 90% | GitHub (2025) |
| Organisations using Copilot | 50,000+ | GitHub (2025) |
| Code generated by AI | 41-46% of all code (2025) | GitClear / GitHub data |
| Enterprise teams needing compliance | Growing -- EU AI Act + US frameworks | Gartner, regulatory analysis |

### SAM Calculation

The subset of the AI code tools market focused on governance, quality, and compliance tooling for AI-assisted development:

- AI code tools market (2025): USD 7.37B
- Governance/quality/security share (estimated 15-20%): **USD 1.1-1.5B**
- Plus AI governance platform spend: **USD 492M (2026)**

**SAM estimate: USD 1.5-2.0 billion (2026)**

**Confidence**: MEDIUM (derived from multiple market segments; no single analyst report covers this exact intersection)

## Market Growth Drivers

1. **AI code volume is accelerating**: 41-46% of code is AI-generated today, trajectory is upward
2. **Regulatory pressure is concrete**: EU AI Act high-risk obligations enforceable August 2026; Gartner predicts regulations to quadruple by 2030
3. **Quality crisis is measurable**: AI-generated code produces 1.7x more defects, 1.4x more critical issues (CodeRabbit State of AI Code Report)
4. **Enterprise budgets are shifting**: AI governance platform spend alone reaches USD 492M in 2026 (Gartner)
5. **Incumbent gap**: No existing tool provides pre-commit, deterministic governance with authorship attribution
