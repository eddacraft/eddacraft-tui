# Classifier / metadata names pip-licenses reports → SPDX.
# licences.toml stays SPDX. The Python driver appends every alias
# whose SPDX is on the allow-list before calling --allow-only.
# Tab-separated: SPDX<TAB>alias
# Do not add these aliases to licences.toml — they are Python-only.
#
# One alias string maps to exactly one SPDX id. Generic Trove names
# that collapse distinct licences (plain "BSD License", generic
# "GNU General Public License v3 (GPLv3)", generic LGPLv3) are
# omitted on purpose: mapping them would fail-open if only one
# variant is on the allow-list.
