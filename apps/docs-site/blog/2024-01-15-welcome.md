Welcome to the EddaCraft documentation site.

EddaCraft builds tools for governed AI-assisted development:

- **Anvil** — Validate AI-generated code at save-time
- **APS** — Define deterministic, hash-stable plans
- **Kindling** — Capture structured observations from sessions

Stay tuned for updates as we release new features and improvements.
