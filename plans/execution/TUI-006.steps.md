## Context

Curated library of 10-15 plan templates covering common scenarios (JWT auth,
REST API, database migration, etc.). Templates are static markdown with variable
placeholders. No AI generation — achieves 90% of value with minimal complexity.

## Steps

### 1. Define template schema

- **Checkpoint:** Template metadata: id, name, description, category, variables
- **Checkpoint:** Variable schema: name, description, default, required
- **Files:** `cli/src/services/template-loader.ts`

### 2. Create template files

- **Checkpoint:** 10-15 templates in `cli/templates/`:
  - `authentication-jwt.md` — JWT authentication flow
  - `rest-api-crud.md` — REST API with CRUD operations
  - `database-migration.md` — Database schema migration
  - `frontend-component.md` — UI component implementation
  - `websocket-realtime.md` — Real-time WebSocket feature
  - `file-upload.md` — File upload handling
  - `caching-layer.md` — Caching implementation
  - `api-integration.md` — Third-party API integration
  - `testing-suite.md` — Test suite setup
  - `ci-cd-pipeline.md` — CI/CD pipeline configuration
- **Checkpoint:** Each template has frontmatter with metadata
- **Files:** `cli/templates/*.md`

### 3. Implement template loader

- **Checkpoint:** `loadTemplates()` reads all templates from directory
- **Checkpoint:** `getTemplate(id)` returns single template
- **Checkpoint:** `renderTemplate(template, variables)` substitutes placeholders
- **Files:** `cli/src/services/template-loader.ts`

### 4. Create TemplateBrowser TUI component

- **Checkpoint:** Lists templates with category grouping
- **Checkpoint:** Shows template preview on selection
- **Checkpoint:** Prompts for variable values
- **Checkpoint:** Keyboard navigation (arrows, enter, escape)
- **Files:** `cli/src/tui/commands/new/TemplateBrowser.tsx`

### 5. Create new command

- **Checkpoint:** `anvil new` launches template browser
- **Checkpoint:** `anvil new <template-id>` uses template directly
- **Checkpoint:** `anvil new --list` shows available templates (CLI mode)
- **Checkpoint:** Outputs rendered template to stdout or file
- **Files:** `cli/src/commands/new.ts`

### 6. Add tests

- **Checkpoint:** Template loader tests

- **Checkpoint:** Template browser component tests
