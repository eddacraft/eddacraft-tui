## Intent

Developers see anti-pattern warnings (AP-001 through AP-007) in the Problems
panel within 200ms of saving a file. Warnings include accurate source locations
for click-to-navigate.

## Prerequisites

- [ ] IDE-001 complete (embedded @anvil/core)
- [ ] Anti-pattern scanner available in core (`analyseAntiPatterns`)

## Steps

### 1. Extend PlanWatcher for source files

- **Checkpoint:** Watcher triggers on .ts/.tsx/.js/.jsx saves, not just plans
- **Pattern:** `packages/vscode-extension/src/services/planWatcher.ts`

### 2. Call embedded anti-pattern scanner

- **Checkpoint:** Save triggers `analyseAntiPatterns` from embedded core
- **Validate:** Console log shows anti-pattern results on save

### 3. Map warnings to VS Code diagnostics

- **Checkpoint:** Anti-pattern warnings appear in Problems panel
- **Pattern:** `packages/vscode-extension/src/services/diagnostics.ts`

### 4. Include source location in diagnostics

- **Checkpoint:** Clicking warning navigates to correct line and column
- **Validate:** Manual test with file containing `// @ts-ignore`

### 5. Add warning code and documentation link

- **Checkpoint:** Each diagnostic shows AP-xxx code with hover explanation
- **Validate:** Hover over warning shows pattern description

### 6. Debounce rapid saves

- **Checkpoint:** Multiple rapid saves trigger single analysis
- **Validate:** Save 5 times quickly, observe single analysis run

## Completion

- [ ] All checkpoints validated
- [ ] Task marked complete in source module
- [ ] AP-001 through AP-007 detectable in VS Code
- [ ] Click-to-navigate works for all warning types
