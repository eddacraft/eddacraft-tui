that predate the two-path journey and never mention Rust; the proposal is a

## Audit of the current set (docs/public/anvil/tutorials/)

- `index.md` (59 ln) — flat list; no journey framing; does not mention the
  in-terminal `anvil tutorial` command.
- `architecture.md` (143 ln) — TypeScript-only examples; healthy content,
  needs Rust example parity and a pointer from the start path.
- `ci.md` (228 ln) — longest page; overlaps the GitHub integration guide
  (SARIF section now lives there); candidate to fold into
  `integrations/github.md` and retire.
- `drift.md` (145 ln) — sound; minor refresh (dashboard cross-link).
- `policies.md` (132 ln) — sound; OPA/Rego niche audience; keep as-is.
- `suppressions.md` (143 ln) — TypeScript examples; overlaps the insights
  suppression-health view and dashboard guide; candidate to fold into a
  guide and retire as a tutorial.
- Not on the web at all: the two beta golden paths. No tutorial walks
  `anvil start` → watch/MCP daily value, and none walks a Rust repo through
  discovery → findings → fix.

## Journey-aligned target set (proposed)

1. **Your first save caught** (new) — the daily-value path end to end:
   `anvil start`, daemon-backed watch, make a bad save, read the finding,
   `anvil status` posture. The flagship tutorial; linked from quickstart
   step 3.
2. **Analyse a Rust project** (new) — discovery wow on a real Rust repo:
   `anvil welcome` / `anvil check --all`, advisory-severity Rust rules,
   what the language profile claims. Closes the "no Rust tutorial" gap
   (v0.8.0 RSTLAN).
3. **Architecture boundaries** (refresh) — add a Rust example beside the
   TypeScript one; cross-link from tutorial 1.
4. **Drift detection** (refresh) — cross-link dashboards/insights.
5. **Custom policies** (keep) — niche but distinct; no overlap.

Retire as tutorials (fold the unique content into the named guide):
- `ci.md` → `integrations/github.md` (CI section).
- `suppressions.md` → dashboard/insights guides (suppression health).

`index.md` is rewritten around the two paths and names the in-terminal
`anvil tutorial` as the interactive sibling.
