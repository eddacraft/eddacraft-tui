# RLB-009 Per-command CLI Benchmark Runner Implementation Plan

**Goal:** Add a safe, Anvil-specific benchmark runner for measuring one finite
`anvil` CLI command at a time.
**Architecture:** Extend `crates/anvil-bench` with a separate command-runner
binary that reuses the existing binary-resolution, process cleanup, fixture, and
Linux process-tree sampling primitives. Keep the stress-runner CLI stable; wire
curated command benchmarks into `pnpm bench` and benchmark history only after the
JSON report shape is stable.
**Tech Stack:** Rust (`std::process`, `serde`, `tempfile`, existing
`anvil-bench` helpers), Bash benchmark orchestration, Python history
normalisation, Markdown docs/APS.

---

## File Map

- `crates/anvil-bench/src/cli_command.rs` — command-benchmark config, runner,
  fixture selection, safe environment, per-iteration samples, aggregate stats,
  and JSON report model.
- `crates/anvil-bench/src/bin/anvil-bench-command.rs` — CLI entry point for
  benchmarking the resolved `anvil` binary with args passed after `--`.
- `crates/anvil-bench/tests/cli_command.rs` — fake-binary integration tests for
  repeat/warmup, exit-code capture, timeout handling, redaction, and report
  shape.
- `crates/anvil-bench/src/lib.rs` — exports the command-benchmark module.
- `crates/anvil-bench/README.md` — documents the manual one-command benchmark
  workflow and guardrails.
- `scripts/bench/run.sh` — optional curated routine command benchmarks once the
  runner/report shape is stable.
- `scripts/bench/to-history.py` — optional normaliser support for curated
  command-benchmark JSON logs.
- `benchmarks/README.md` — optional `cli_commands` history-schema extension.
- `plans/modules/resource-load-benchmarking.aps.md` — RLB-009 status and
  closeout evidence.
- `plans/execution/RLB-009.actions.md` — this executable APS plan.

### 1. Pin the command-runner contract

- **Work Item:** RLB-009
- **Checkpoint:** Tests define repeat/warmup semantics, finite-command timeout,
  non-shell execution, safe environment defaults, and redacted argument metadata.
- **Validate:** `cargo test -p anvil-bench cli_command --test cli_command`

### 2. Add command-benchmark report model

- **Work Item:** RLB-009
- **Checkpoint:** Per-iteration samples and aggregate p50/p95/p99 stats round-trip
  through stable JSON without raw argument values by default.
- **Validate:** `cargo test -p anvil-bench cli_command_report`

### 3. Implement the `anvil-bench-command` runner

- **Work Item:** RLB-009
- **Depends on:** 1, 2
- **Checkpoint:** The runner resolves the `anvil` binary, benchmarks only direct
  Anvil args after `--`, uses isolated state/fixtures, and cleans up process
  groups on timeout or failure.
- **Validate:** `cargo test -p anvil-bench cli_command && cargo run -p anvil-bench --bin anvil-bench-command -- --help`

### 4. Prove a real finite CLI command benchmark

- **Work Item:** RLB-009
- **Depends on:** 3
- **Checkpoint:** A release `anvil status --verify` benchmark completes on an
  empty fixture and writes an auditable JSON report.
- **Validate:** `cargo build -p eddacraft-anvil --release --bin anvil && ANVIL_BENCH_ANVIL_BIN=target/release/anvil cargo run -p anvil-bench --bin anvil-bench-command -- --name status-verify --repeat 3 --warmup 1 --fixture empty -- status --verify`

### 5. Decide routine-suite/history integration

- **Work Item:** RLB-009
- **Depends on:** 4
- **Checkpoint:** Either a small curated command-benchmark set is added to
  `pnpm bench` plus `benchmarks/history`, or the module records an explicit
  deferral with the manual command documented.
- **Validate:** `pnpm bench -- --skip-resource-budget --skip-kindling` if wired;
  otherwise `python3 scripts/bench/to-history.py --help && pnpm docs:check`

### 6. Review and close out RLB-009

- **Work Item:** RLB-009
- **Depends on:** 5
- **Checkpoint:** RLB-009 records implementation evidence, docs mention the
  command-runner guardrails, and no generated indexes or APS checks are stale.
- **Validate:** `cargo fmt --check && cargo clippy -p anvil-bench --all-targets -- -D warnings && cargo test -p anvil-bench && pnpm aps:index:check && pnpm aps:active-lint && pnpm docs:check && pnpm lint:md && git diff --check`
