## Context

Post a summary comment on the PR with warning details, and set a commit status
check. By default, the status is "neutral" (informational) — it doesn't block
the PR. With `fail-on-warnings: true`, it becomes a failing check.

## Steps

### 1. Add PR comment step

Use `actions/github-script` to post/update a comment:

```yaml
- name: Post PR comment
  if: github.event_name == 'pull_request'
  uses: actions/github-script@v7
  with:
    script: |
      const warnings = ${{ steps.anvil.outputs.warnings-count }};
      const errors = ${{ steps.anvil.outputs.errors-count }};

      let body = '## 🔨 Anvil Check Results\n\n';

      if (warnings === 0 && errors === 0) {
        body += '✅ **No issues found!**\n';
      } else {
        body += `| Category | Count |\n|----------|-------|\n`;
        body += `| ⚠️ Warnings | ${warnings} |\n`;
        body += `| ❌ Errors | ${errors} |\n`;
      }

      // Find and update existing comment
      const { data: comments } = await github.rest.issues.listComments({
        owner: context.repo.owner,
        repo: context.repo.repo,
        issue_number: context.issue.number,
      });

      const existing = comments.find(c => 
        c.body.includes('🔨 Anvil Check Results'));

      if (existing) {
        await github.rest.issues.updateComment({
          owner: context.repo.owner,
          repo: context.repo.repo,
          comment_id: existing.id,
          body,
        });
      } else {
        await github.rest.issues.createComment({
          owner: context.repo.owner,
          repo: context.repo.repo,
          issue_number: context.issue.number,
          body,
        });
      }
```

### 2. Add commit status step

```yaml
- name: Set commit status
  uses: actions/github-script@v7
  with:
    script: |
      const warnings = ${{ steps.anvil.outputs.warnings-count }};
      const errors = ${{ steps.anvil.outputs.errors-count }};
      const failOnWarnings = '${{ inputs.fail-on-warnings }}' === 'true';

      let state = 'success';
      let description = 'No issues found';

      if (errors > 0) {
        state = 'failure';
        description = `${errors} error(s) found`;
      } else if (warnings > 0 && failOnWarnings) {
        state = 'failure';
        description = `${warnings} warning(s) found (blocking mode)`;
      } else if (warnings > 0) {
        state = 'neutral';
        description = `${warnings} warning(s) found`;
      }

      await github.rest.repos.createCommitStatus({
        owner: context.repo.owner,
        repo: context.repo.repo,
        sha: context.sha,
        state,
        description,
        context: 'Anvil Check',
      });
```

### 3. Add check run for inline annotations

```yaml
- name: Create check run with annotations
  if: steps.anvil.outputs.warnings-count > 0
  uses: actions/github-script@v7
  with:
    script: |
      const result = JSON.parse(`${{ steps.anvil.outputs.result-json }}`);

      const annotations = (result.warnings || []).slice(0, 50).map(w => ({
        path: w.file,
        start_line: w.line,
        end_line: w.line,
        annotation_level: w.severity === 'error' ? 'failure' : 'warning',
        message: `[${w.id}] ${w.message}`,
      }));

      await github.rest.checks.create({
        owner: context.repo.owner,
        repo: context.repo.repo,
        name: 'Anvil Check',
        head_sha: context.sha,
        status: 'completed',
        conclusion: 'neutral',
        output: {
          title: 'Anvil Check Results',
          summary: `Found ${annotations.length} issue(s)`,
          annotations,
        },
      });
```

### 4. Document required permissions

Add to action README:

```yaml
permissions:
  contents: read
  pull-requests: write
  statuses: write
  checks: write
```
