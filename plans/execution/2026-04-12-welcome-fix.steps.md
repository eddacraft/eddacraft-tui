# Welcome & First-User Experience Fix — Implementation Plan

**Goal:** Fix the broken first-user experience so that install → first fix takes
under 3 minutes with real project scanning, working config persistence, and
functional welcome hub actions.

**Architecture:** The welcome flow is a state machine in `welcome.rs` that
orchestrates TUI surfaces (onboarding → init → discovery → tutorial → hub).
Fixes target the orchestrator wiring and the stub implementations — the
individual surface UIs are already built and tested. The real scan integrates
`anvil-checks` secret + antipattern scanners with `ScanFilter` path exclusions,
converting results to the existing `Finding` type used by the discovery surface.

**Tech Stack:** Rust, ratatui, anvil-checks (secret + antipattern scanners),
anvil-kernel (watcher for watch mode), clap (CLI args)

**Spec:** `plans/specs/2026-04-12-welcome-fix-design.md`
**Module:** WELCOME (reopened)

**Files:**

  1. Walk files from current directory using `walkdir`, filtered by `ScanFilter::default_excludes()`
  2. Cap at 500 files to keep scan under 10s
  3. For each file, read content, run:
     - `anvil_checks::secret::scanner::scan_content(&content, &path, &SecretCheckConfig::default())`
     - `anvil_checks::antipattern::scanner::scan_file(&path, &content, None)`
  4. Convert `SecretFinding` → `Finding` (source: `FindingSource::Secret`, severity: `Error`)
  5. Convert `Warning` → `Finding` (source: `FindingSource::AntiPattern`, map `WarningSeverity`)
  6. Set `files_scanned` and `duration_ms` from actual values
- [ ] If zero real findings after scan, call `showcase::showcase_findings()` as fallback (WELCOME-007)
- [ ] Update `discovery.set_results()` with real results
- [ ] Test manually: run in a project with a TODO comment or test secret
- [ ] Commit: `fix(welcome): wire real secret + antipattern scan into discovery (WELCOME-013)`

**Conversion functions (add to `welcome.rs` or a helper module):**

```rust
fn secret_to_finding(f: &anvil_checks::secret::types::SecretFinding) -> Finding {
    Finding {
        file: f.file.clone(),
        line: Some(f.line),
        severity: FindingSeverity::Error,
        source: FindingSource::Secret,
        title: format!("Secret detected: {}", f.pattern_name),
        message: f.redacted_line.clone(),
        suggestion: "Move the value to an environment variable or secrets manager.".to_string(),
    }
}

fn warning_to_finding(w: &anvil_checks::antipattern::types::Warning) -> Finding {
    Finding {
        file: w.location.file.clone(),
        line: Some(w.location.line),
        severity: match w.severity {
            WarningSeverity::Error => FindingSeverity::Error,
            WarningSeverity::Warning => FindingSeverity::Warning,
            WarningSeverity::Info => FindingSeverity::Info,
        },
        source: FindingSource::AntiPattern,
        title: w.title.clone(),
        message: w.message.clone(),
        suggestion: w.suggestion.clone(),
    }
}
```
