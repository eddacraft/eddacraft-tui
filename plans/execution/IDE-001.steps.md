## Intent

Embed lightweight `@anvil/core` functions directly in the VS Code extension for
sub-100ms feedback on file save. Heavy operations (gates, OPA, coverage) remain
CLI-based.

## Prerequisites

- [ ] `@anvil/core` exports required functions (validateSchema, detectFormat,
      analyseAntiPatterns)
- [ ] Extension builds with esbuild (already configured)

## Steps

### 1. Identify core exports needed

- **Checkpoint:** List of required exports from @anvil/core documented
- **Pattern:** `core/src/index.ts` — existing public API

### 2. Add @anvil/core as bundled dependency

- **Checkpoint:** Extension bundles core without external require errors
- **Validate:** `pnpm -F vscode-extension run build`

### 3. Create embedded analysis service

- **Checkpoint:** New service wraps core functions for VS Code context
- **Pattern:** `packages/vscode-extension/src/services/anvilService.ts`

### 4. Wire fast-path to file save handler

- **Checkpoint:** Save triggers embedded analysis, not CLI subprocess
- **Validate:** Manual test: save file, observe < 200ms response

### 5. Maintain CLI fallback for heavy operations

- **Checkpoint:** Gate/export commands still use CLI subprocess
- **Validate:** `anvil.gate` command works as before

### 6. Verify bundle size acceptable

- **Checkpoint:** Extension VSIX < 2MB
- **Validate:** `pnpm -F vscode-extension run package && ls -la *.vsix`

## Completion

- [ ] All checkpoints validated
- [ ] Task marked complete in source module
- [ ] Extension builds without errors
- [ ] Fast-path latency < 200ms confirmed
