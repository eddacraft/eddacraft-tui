## Context

For performance, the action should only analyse files changed in the PR, not the
entire codebase. GitHub provides changed files via the `gh` CLI or API.

## Steps

### 1. Add changed files detection step

```yaml
- name: Get changed files
  id: changed-files
  shell: bash
  env:
    GH_TOKEN: ${{ github.token }}
  run: |
    if [[ "${{ github.event_name }}" == "pull_request" ]]; then
      FILES=$(gh pr view ${{ github.event.pull_request.number }} \
        --json files -q '.files[].path' | tr '\n' ' ')
    else
      FILES=$(git diff --name-only ${{ github.event.before }} \
        ${{ github.sha }} | tr '\n' ' ')
    fi
    echo "files=$FILES" >> $GITHUB_OUTPUT
```

### 2. Filter to analysable files

Only pass TypeScript/JavaScript files to Anvil:

```yaml
- name: Filter analysable files
  id: filter-files
  shell: bash
  run: |
    FILES="${{ steps.changed-files.outputs.files }}"
    FILTERED=""
    for FILE in $FILES; do
      case "$FILE" in
        *.ts|*.tsx|*.js|*.jsx|*.mjs|*.cjs)
          FILTERED="$FILTERED $FILE"
          ;;
      esac
    done
    echo "files=$FILTERED" >> $GITHUB_OUTPUT
```

### 3. Update Anvil step to use filtered files

```yaml
- name: Run Anvil check
  id: anvil
  if: steps.filter-files.outputs.files != ''
  shell: bash
  run: |
    anvil check ${{ steps.filter-files.outputs.files }} --output json
```

### 4. Handle no-files case gracefully

```yaml
- name: Skip if no files to check
  if: steps.filter-files.outputs.files == ''
  shell: bash
  run: |
    echo "No analysable files changed, skipping Anvil check"
    echo "warnings-count=0" >> $GITHUB_OUTPUT
    echo "errors-count=0" >> $GITHUB_OUTPUT
```

### 5. Test scenarios

Test with:

- PR with TypeScript files → runs check
- PR with only markdown files → skips gracefully
- PR with mixed files → filters correctly
- Push event → uses commit diff
