## Prerequisites

- [ ] Bun runtime installed (required by OpenTUI)
- [ ] Understanding of OpenTUI React renderer API

## Context

OpenTUI (`@opentui/core`, `@opentui/react`) provides a Zig-native terminal
rendering engine with React reconciler. Components live in `cli/src/tui/` to
keep TUI code separate from core CLI logic.

Key OpenTUI primitives: `<box>`, `<text>`, `<input>`, `<select>`, `<code>`.

## Steps

### 1. Install OpenTUI dependencies

- **Checkpoint:** `@opentui/core`, `@opentui/react`, `react` in cli/package.json
- **Checkpoint:** Bun runtime requirement documented
- **Files:** `cli/package.json`

### 2. Create TUI directory structure

- **Checkpoint:** `cli/src/tui/` directory exists with subdirectories:
  - `components/layout/` — Box, Container, Grid
  - `components/display/` — Header, InfoPanel, List, Table
  - `components/input/` — Select, Checkbox, TextInput
  - `components/feedback/` — Spinner, StatusMessage, ProgressBar
  - `utils/` — renderer, colours, icons
- **Files:** `cli/src/tui/**/*`

### 3. Implement TTY detection utility

- **Checkpoint:** `isTUIAvailable()` function detects TTY, respects `NO_TUI=1`

### 4. Create TUI renderer wrapper

- **Checkpoint:** `renderTUI(Component, props)` wraps OpenTUI's createRoot
