## Prerequisites

## Context

Detect first-time Anvil usage and display a friendly welcome screen explaining
the value proposition. Goal: make Anvil's value clear within 30 seconds.

First-run detection via `.anvil/first-run` marker file.

## Steps

### 1. Implement first-run detection

- **Checkpoint:** `isFirstRun()` checks for `.anvil/first-run` marker
- **Checkpoint:** `markFirstRunComplete()` creates marker file
- **Checkpoint:** Respects `ANVIL_SKIP_WELCOME=1` environment variable
- **Files:** `cli/src/services/first-run-detector.ts`

### 2. Create Welcome TUI component

- **Checkpoint:** Shows Anvil logo/banner
- **Checkpoint:** Brief value proposition (2-3 sentences)
- **Checkpoint:** Quick start options: Init, Tutorial, Skip
- **Files:** `cli/src/tui/commands/welcome/Welcome.tsx`

### 3. Define welcome content

- **Checkpoint:** Value proposition copy is clear and compelling
- **Checkpoint:** UK English spelling throughout
- **Checkpoint:** No marketing fluff — focus on developer benefit
- **Files:** `cli/src/tui/commands/welcome/content.ts`

### 4. Integrate with CLI entry point

- **Checkpoint:** Welcome shown on first bare `anvil` command
- **Checkpoint:** Welcome NOT shown for explicit commands (`anvil init`, etc.)
- **Checkpoint:** Welcome shown only once (marker file created after)
- **Files:** `cli/src/index.ts`

### 5. Add tests

- **Checkpoint:** First-run detection tests
- **Checkpoint:** Welcome component render tests
- **Validate:** `nx test cli --testNamePattern="welcome\|first-run"` — passes
- **Files:** `cli/src/services/__tests__/first-run-detector.test.ts`
