# Steps: MCP-001

## Prerequisites

- [ ] Node.js 20+ available
- [ ] pnpm workspace configured
- [ ] `@eddacraft/anvil-core` builds successfully

## Steps

### 1. Create package directory structure

- **Checkpoint:** `packages/mcp-server/` exists with src/, package.json,
  tsconfig.json
- **Validate:** `ls packages/mcp-server/src/index.ts`
- **Pattern:** `packages/adapters/` (sibling package structure)

### 2. Configure package.json with MCP SDK dependency

- **Checkpoint:** Package has `@modelcontextprotocol/sdk` and bin entry
  configured
- **Validate:**
  `pnpm -F mcp-server exec -- node -e "require('@modelcontextprotocol/sdk')"`
- **Pattern:** `packages/aps/package.json` (bin configuration)

### 3. Configure TypeScript with ESM and NodeNext

- **Checkpoint:** tsconfig.json extends base, uses NodeNext module resolution
- **Validate:** `pnpm -F mcp-server typecheck`
- **Pattern:** `packages/adapters/tsconfig.json`

### 4. Implement server entry point with stdio transport

- **Checkpoint:** index.ts creates Server, connects StdioServerTransport
- **Validate:** `echo '{}' | pnpm -F mcp-server start 2>&1 | head -1`

### 5. Register MCP capabilities (tools, resources)

- **Checkpoint:** Server advertises capabilities in handshake response
- **Validate:** MCP initialize request returns capabilities object

### 6. Add placeholder tool handlers

- **Checkpoint:** ListTools returns empty array, CallTool returns
  not-implemented
- **Validate:** `pnpm -F mcp-server test`

### 7. Create AGENTS.md documentation

- **Checkpoint:** Package has AGENTS.md with MCP-specific guidance
- **Validate:** `test -f packages/mcp-server/AGENTS.md`
- **Pattern:** `packages/adapters/AGENTS.md`

### 8. Register package in workspace

- **Checkpoint:** `pnpm build` includes mcp-server, no errors
- **Validate:** `pnpm build && ls packages/mcp-server/dist/index.js`

## Completion

- [ ] All checkpoints validated
- [ ] `pnpm -F mcp-server test` passes
- [ ] Task marked complete in source module
