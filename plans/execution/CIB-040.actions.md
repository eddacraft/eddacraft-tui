# CIB-040 Help Text Layout Implementation Plan

**Goal:** Apply the CLIC-010 help layout to every visible `anvil` command and add
a CI lint that prevents future drift.
**Architecture:** Keep clap as the parser and source of command truth, but route
runtime help rendering and lint traversal through one shared help-layout layer.
The layout layer augments generated clap help with command-specific
when-to-use guidance, standard common-flag descriptions, and a docs pointer
sourced from the existing CLI surface runbook.
**Tech Stack:** Rust (`clap` derive/builder APIs, `assert_cmd` integration tests),
Markdown runbooks, APS validation scripts.

---

## File Map

- `crates/anvil-cli/src/main.rs` — route CLI parsing and registered-command
  introspection through the shared help-layout command builder.
- `crates/anvil-cli/src/help_layout.rs` — define the CLIC-010 metadata table,
  recursive clap command augmentation, docs anchors, and lint helpers.
- `crates/anvil-cli/src/commands/**` — adjust command summaries or subcommand
  metadata only where the central lint proves a command-specific gap.
- `crates/anvil-cli/tests/help_layout.rs` — CI-facing CLIC-010 lint over every
  non-hidden command path plus representative rendered-help assertions.
- `docs/runbooks/cli-surface.md` — canonical when-to-use/docs anchors; update
  only when generated help exposes a stale or missing command entry.
- `plans/modules/continuous-improvement-backlog.aps.md` — CIB-040 status and
  closeout evidence.
- `plans/index.aps.md` — CIB row prose if the item status/count changes.
- `plans/reviews/2026-06-27-cib-040-help-layout.md` — Council/validation receipt
  when implementation closes.

## Waves

| Wave | Actions | Gate |

| 1 | 1, 2 | CLIC-010 lint fails for the current help surface and names actionable gaps. |

### 1. Inventory visible command paths

- **Work Item:** CIB-040
- **Checkpoint:** Clap traversal lists every non-hidden command path with its
  runbook anchor candidate.
- **Validate:** `cargo test -p eddacraft-anvil help_layout_inventory --test help_layout`

### 2. Add failing CLIC-010 lint

- **Work Item:** CIB-040
- **Checkpoint:** CI test asserts each visible command help has summary,
  when-to-use, common flags, and learn-more sections.
- **Validate:** `cargo test -p eddacraft-anvil clic_010 --test help_layout`

### 3. Centralise runtime help augmentation

- **Work Item:** CIB-040
- **Depends on:** 1, 2
- **Checkpoint:** `Cli::command()` is augmented before parse/render and normal
  command dispatch remains unchanged.
- **Validate:** `cargo test -p eddacraft-anvil help_layout --test help_layout && cargo test -p eddacraft-anvil main::tests::registered_command_names_exclude_hidden_aliases`

### 4. Populate command-specific CLIC-010 metadata

- **Work Item:** CIB-040
- **Depends on:** 3
- **Checkpoint:** Every non-hidden top-level and nested command has a concise
  when-to-use hint and docs pointer, with no internal IDs in rendered help.
- **Validate:** `cargo test -p eddacraft-anvil clic_010 --test help_layout`

### 5. Reconcile command summaries and runbook anchors

- **Work Item:** CIB-040
- **Depends on:** 4
- **Checkpoint:** User-visible summaries are imperative and command docs anchors
  resolve in `docs/runbooks/cli-surface.md`.
- **Validate:** `cargo test -p eddacraft-anvil help_layout --test help_layout && pnpm docs:check`

### 6. Review and close out CIB-040

- **Work Item:** CIB-040
- **Depends on:** 5
- **Checkpoint:** Mini Council receipt and APS status update capture the
  completed help-layout pass.
- **Validate:** `cargo fmt --check && cargo clippy -p eddacraft-anvil --all-targets -- -D warnings && pnpm aps:index:check && pnpm aps:active-lint && pnpm docs:check && pnpm format:check`
