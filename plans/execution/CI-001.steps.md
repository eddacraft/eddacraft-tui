## Prerequisites

- [x] CLI `anvil check` command exists
- [x] CLI `--output json` flag exists
- [x] Gate runner with JSON output mode

## Context

Create a GitHub composite action that wraps the Anvil CLI. Composite actions are
preferred over JavaScript/Docker actions for simplicity and transparency.

Target location: `.github/actions/anvil-check/`

## Steps

### 2. Define action metadata and inputs

```yaml
name: 'Anvil Check'
description: 'Run Anvil quality gates on your codebase'
author: 'Anvil'

inputs:
  node-version:
    description: 'Node.js version to use'
    required: false
    default: '20'
  working-directory:
    description: 'Directory to run Anvil in'
    required: false
    default: '.'
  fail-on-warnings:
    description: 'Fail the check if warnings are found'
    required: false
    default: 'false'
  check-type:
    description: 'Type of check: "gate" or "check"'
    required: false
    default: 'check'
  files:
    description: 'Specific files to check (space-separated)'
    required: false
    default: ''
```

### 3. Define action outputs

```yaml
outputs:
  warnings-count:
    description: 'Total number of warnings found'
    value: ${{ steps.anvil.outputs.warnings-count }}
  errors-count:
    description: 'Total number of errors found'
    value: ${{ steps.anvil.outputs.errors-count }}
  result-json:
    description: 'Full JSON result from Anvil'
    value: ${{ steps.anvil.outputs.result-json }}
  exit-code:
    description: 'Exit code from Anvil'
    value: ${{ steps.anvil.outputs.exit-code }}
```

### 4. Implement composite action steps

```yaml
runs:
  using: 'composite'
  steps:
    - name: Setup Node.js
      uses: actions/setup-node@v4
      with:
        node-version: ${{ inputs.node-version }}

    - name: Install Anvil CLI
      shell: bash
      run: npm install -g @anvil/cli

    - name: Run Anvil check
      id: anvil
      shell: bash
      working-directory: ${{ inputs.working-directory }}
      run: |
        set +e
        RESULT=$(anvil ${{ inputs.check-type }} ${{ inputs.files }} --output json 2>&1)
        EXIT_CODE=$?
        set -e

        echo "exit-code=$EXIT_CODE" >> $GITHUB_OUTPUT
        echo "result-json<<EOF" >> $GITHUB_OUTPUT
        echo "$RESULT" >> $GITHUB_OUTPUT
        echo "EOF" >> $GITHUB_OUTPUT

        WARNINGS=$(echo "$RESULT" | jq -r '.summary.warnings // 0')
        ERRORS=$(echo "$RESULT" | jq -r '.summary.errors // 0')
        echo "warnings-count=$WARNINGS" >> $GITHUB_OUTPUT
        echo "errors-count=$ERRORS" >> $GITHUB_OUTPUT

        if [[ "${{ inputs.fail-on-warnings }}" == "true" && $EXIT_CODE -ne 0 ]]; then
          exit 1
        fi
```
