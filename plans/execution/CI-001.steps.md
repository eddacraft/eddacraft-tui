## Context

Create a GitHub composite action that wraps the Anvil CLI. Composite actions are
preferred over JavaScript/Docker actions for simplicity and transparency.

Target location: `.github/actions/anvil-check/`

### 2. Define action metadata and inputs

```yaml
name: 'Anvil Check'
description: 'Run Anvil quality gates on your codebase'
author: 'Anvil'
branding:
  icon: 'shield'
  color: 'blue'

inputs:
  node-version:
    description:
      'Explicit Node.js version (e.g., 20, 22). If empty, auto-detects from
      project files.'
    required: false
    default: ''
  node-version-file:
    description:
      'File to read Node version from. Defaults to .node-version if it exists.'
    required: false
    default: ''
  working-directory:
    description: 'Directory to run Anvil in (for monorepos)'
    required: false
    default: '.'
  fail-on-warnings:
    description: 'Fail the check if warnings are found'
    required: false
    default: 'false'
  check-type:
    description: 'Type of check: "gate" or "check"'
    required: false
    default: 'check'
  files:
    description:
      'Specific files to check (space-separated). If empty, uses changed files.'
    required: false
    default: ''
```

**Node version resolution priority:**

1. Explicit `node-version` input → use that
2. Explicit `node-version-file` input → read from that file
3. Auto-detect from `.node-version`, `.nvmrc`, or `package.json`
4. Fallback to Node 20 (Anvil minimum)

### 4. Implement composite action steps

```yaml
runs:
  using: 'composite'
  steps:
    # Step 1: Detect Node version file if not explicitly provided
    - name: Detect Node version file
      id: detect-node
      shell: bash
      working-directory: ${{ inputs.working-directory }}
      run: |
        if [[ -n "${{ inputs.node-version }}" ]]; then
          echo "source=explicit" >> $GITHUB_OUTPUT
          echo "Using explicit node-version: ${{ inputs.node-version }}"
        elif [[ -n "${{ inputs.node-version-file }}" ]]; then
          echo "source=file" >> $GITHUB_OUTPUT
          echo "file=${{ inputs.node-version-file }}" >> $GITHUB_OUTPUT
          echo "Using node-version-file: ${{ inputs.node-version-file }}"
        elif [[ -f ".node-version" ]]; then
          echo "source=file" >> $GITHUB_OUTPUT
          echo "file=.node-version" >> $GITHUB_OUTPUT
          echo "Auto-detected .node-version"
        elif [[ -f ".nvmrc" ]]; then
          echo "source=file" >> $GITHUB_OUTPUT
          echo "file=.nvmrc" >> $GITHUB_OUTPUT
          echo "Auto-detected .nvmrc"
        elif [[ -f "package.json" ]]; then
          echo "source=file" >> $GITHUB_OUTPUT
          echo "file=package.json" >> $GITHUB_OUTPUT
          echo "Auto-detected package.json"
        else
          echo "source=fallback" >> $GITHUB_OUTPUT
          echo "No version file found, using fallback (Node 20)"
        fi

    # Step 2: Setup Node.js with detected version
    - name: Setup Node.js
      uses: actions/setup-node@v4
      with:
        node-version:
          ${{ inputs.node-version || (steps.detect-node.outputs.source ==
          'fallback' && '20' || '') }}
        node-version-file: ${{ steps.detect-node.outputs.file || '' }}

    # Step 3: Install Anvil CLI
    - name: Install Anvil CLI
      shell: bash
      run: npm install -g @anvil/cli

    # Step 4: Run Anvil check
    - name: Run Anvil check
      id: anvil
      shell: bash
      working-directory: ${{ inputs.working-directory }}
      run: |
        set +e
        RESULT=$(anvil ${{ inputs.check-type }} ${{ inputs.files }} --output json 2>&1)
        EXIT_CODE=$?
        set -e

        echo "exit-code=$EXIT_CODE" >> $GITHUB_OUTPUT
        echo "result-json<<EOF" >> $GITHUB_OUTPUT
        echo "$RESULT" >> $GITHUB_OUTPUT
        echo "EOF" >> $GITHUB_OUTPUT

        # Extract counts from JSON (handle missing fields gracefully)
        WARNINGS=$(echo "$RESULT" | jq -r '.summary.warnings // 0' 2>/dev/null || echo "0")
        ERRORS=$(echo "$RESULT" | jq -r '.summary.errors // 0' 2>/dev/null || echo "0")
        echo "warnings-count=$WARNINGS" >> $GITHUB_OUTPUT
        echo "errors-count=$ERRORS" >> $GITHUB_OUTPUT

        # Fail if configured to block on warnings
        if [[ "${{ inputs.fail-on-warnings }}" == "true" && $EXIT_CODE -ne 0 ]]; then
          exit 1
        fi

        # Always exit 0 unless blocking mode - let status check handle pass/fail
        exit 0
```
