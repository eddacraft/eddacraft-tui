# CRB-029: Expand Test Coverage for Untested CLI Commands

## Context

13 CLI commands have no command-level tests. Existing test patterns use
`vi.hoisted()` mocks, `createTestWorkspace()` helpers, and
`command.parseAsync()` for execution. Tests colocate as `*.test.ts` beside
command files or under `__tests__/`.

## Actions

### 1. Add tests for trivial auth commands (logout, whoami, login)

- **Purpose:** Cover the simplest commands first to establish velocity
- **Produces:** `logout.test.ts`, `whoami.test.ts`, `login.test.ts`
- **Checkpoint:** Three auth commands have structural and behavioural tests
- **Validate:** `pnpm -F anvil-cli test -- --testNamePattern="logout|whoami|login"`

### 2. Add tests for thin wrapper commands (release, validate)

- **Purpose:** Cover commands that delegate to a single service
- **Produces:** `release.test.ts`, `validate.test.ts`
- **Checkpoint:** Wrapper commands test option forwarding and delegation
- **Validate:** `pnpm -F anvil-cli test -- --testNamePattern="release|validate"`

### 3. Add tests for medium-complexity commands (authorship, explain)

- **Purpose:** Cover multi-mode commands with subcommands or flag branches
- **Produces:** `authorship.test.ts`, `explain.test.ts`
- **Note:** `audit` already has command-level coverage via
  `commands/__tests__/audit-spinner.test.ts`
- **Checkpoint:** Each command mode has at least one happy-path test
- **Validate:** `pnpm -F anvil-cli test -- --testNamePattern="authorship|explain"`

### 4. Add tests for complex commands (drift, new, welcome, plan, architecture)

- **Purpose:** Cover commands with multiple subcommands and TUI branching
- **Produces:** `drift.test.ts`, `new.test.ts`, `welcome.test.ts`,
  `plan.test.ts`, `architecture.test.ts`
- **Checkpoint:** Subcommand registration and key paths have coverage
- **Validate:** `pnpm -F anvil-cli test -- --testNamePattern="drift|new|welcome|plan|architecture"`

### 5. Run full test suite and update CRB-029 status

- **Purpose:** Confirm no regressions and mark task complete
- **Checkpoint:** Full CLI test suite passes, CRB-029 marked Complete
- **Validate:** `pnpm -F anvil-cli test`
