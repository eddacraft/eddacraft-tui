## Steps

### 1. Add basic auth to bundle manager

- **Checkpoint:** HTTP Basic auth header sent when credentials configured
- **Validate:** Unit test with mock server

### 2. Add credential storage

- **Checkpoint:** Credentials stored securely (keychain or encrypted file)
- **Pattern:** Follow platform conventions

### 3. Create bundle list command

- **Checkpoint:** `anvil policy bundle list` shows configured bundles
- **Validate:** Manual CLI test

### 4. Create bundle add command

- **Checkpoint:** `anvil policy bundle add <url>` registers bundle
- **Validate:** Bundle appears in config

### 5. Create bundle remove command

- **Checkpoint:** `anvil policy bundle remove <name>` unregisters bundle
- **Validate:** Bundle removed from config

### 6. Create bundle sync command

- **Checkpoint:** `anvil policy bundle sync` downloads all bundles
- **Validate:** Bundles downloaded and verified

### 7. Add CLI tests

- **Checkpoint:** Commands tested with mock bundles
- **Validate:** `nx test cli --testNamePattern="bundle"`
