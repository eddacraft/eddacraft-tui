## Context

Default rule definitions covering destructive git and filesystem operations.
Rules ported from claude-code-safety-net test cases. Each rule has id, reason,
suggestion, and references.

## Steps

### 1. Define git operation rules (CMDSAF-004)

- **Checkpoint:** 15+ git rules defined covering:
  - `git reset --hard` — block (destroys uncommitted changes)
  - `git checkout --` — block (discards working tree)
  - `git restore` without `--staged` — block (discards changes)
  - `git push --force` without `--force-with-lease` — block (rewrites history)
  - `git clean -f` — warn (removes untracked files)
  - `git branch -D` — warn (force delete without merge check)
  - `git stash drop/clear` — warn (permanently deletes stash)
- **Checkpoint:** Safe exceptions defined:
  - `git checkout -b` — allow (branch creation)
  - `git restore --staged` — allow (unstaging)
  - `git push --force-with-lease` — allow (safer force push)
  - `git branch -d` — allow (safe delete with merge check)
- **Checkpoint:** All block/warn rules have suggestion field
- **Validate:** `nx test core --testNamePattern="default git rules"` — passes
- **Files:** `core/src/gate/rules/default-git-rules.ts`,
  `core/src/gate/rules/default-git-rules.test.ts`

### 2. Define filesystem rules (CMDSAF-005)

- **Checkpoint:** 10+ filesystem rules defined covering:
  - `rm -rf /` — block (root deletion)
  - `rm -rf ~` or `$HOME` — block (home deletion)
  - `rm -rf .` — block (current directory)
  - `rm -rf ..` paths — block (parent traversal)
  - `rm -rf` general — block (destructive)
- **Checkpoint:** Safe exceptions defined:
  - `rm -rf /tmp/*` — allow (temp directory)
  - `rm -rf node_modules` — allow (reproducible)
  - `rm -rf dist`, `build`, `target` — allow (build artifacts)
  - `rm -rf .next`, `.cache`, `coverage` — allow (cache directories)
- **Checkpoint:** Flag variants handled (-rf, -fr, --recursive --force)
- **Validate:** `nx test core --testNamePattern="default filesystem rules"` —
  passes
- **Files:** `core/src/gate/rules/default-filesystem-rules.ts`,
  `core/src/gate/rules/default-filesystem-rules.test.ts`
