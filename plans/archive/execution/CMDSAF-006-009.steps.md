## Context

## Steps

### 1. Implement CommandSafetyCheck (CMDSAF-006)

- **Checkpoint:** `CommandSafetyCheck` implements `GateCheck` interface
- **Checkpoint:** `run(plan, config)` extracts commands from `proposed_changes`
- **Checkpoint:** Check parses each command, matches against rules
- **Checkpoint:** Returns `failed` if any blocked, `warning` if warned, `passed`
  otherwise
- **Checkpoint:** Result details include blocked/warned commands with reasons
- **Validate:** `nx test core --testNamePattern="CommandSafetyCheck"` — passes
- **Files:** `core/src/gate/checks/command-safety.check.ts`,
  `core/src/gate/checks/command-safety.check.test.ts`

### 2. Implement configuration system (CMDSAF-007)

- **Checkpoint:** `DEFAULT_COMMAND_SAFETY_CONFIG` defines sensible defaults
- **Checkpoint:** `loadCommandSafetyConfig(userConfig)` merges with defaults
- **Checkpoint:** Config supports:
  - `enabled` — toggle check on/off
  - `rules.disabled` — disable specific rule IDs
  - `rules.overrides` — change action/severity for rules
  - `rules.custom` — add custom rules
- **Validate:** `nx test core --testNamePattern="command safety config"` —
  passes
- **Files:** `core/src/gate/config/command-safety-config.ts`,
  `core/src/gate/config/command-safety-config.test.ts`

### 3. Implement message formatting (CMDSAF-008)

- **Checkpoint:** `CommandSafetyFormatter.formatBlockedCommand(result)` returns
  user-friendly message
- **Checkpoint:** Message includes: command, reason, suggestion, reference
- **Checkpoint:** Warning format distinct from block format
- **Checkpoint:** Summary format shows counts (X blocked, Y warned of Z total)
- **Validate:** `nx test core --testNamePattern="CommandSafetyFormatter"` —
  passes
- **Files:** `core/src/gate/formatters/command-safety-formatter.ts`,
  `core/src/gate/formatters/command-safety-formatter.test.ts`

### 4. CLI integration (CMDSAF-009)

- **Checkpoint:** `CommandSafetyCheck` registered with gate runner
- **Checkpoint:** `anvil gate --skip-command-safety` flag available
- **Checkpoint:** Config loaded from `.anvilrc` `commandSafety` section
- **Validate:** `anvil gate --help` shows command safety options
- **Files:** `cli/src/commands/gate.ts`

### 5. Documentation (CMDSAF-009)

- **Checkpoint:** Configuration reference documents all options
