## Context

Ink (`ink`) provides a React renderer for CLI applications, using Yoga for
flexbox layouts. Components live in `cli/src/tui/` to keep TUI code separate
from core CLI logic.

**Why Ink over OpenTUI:** OpenTUI requires Bun runtime (uses `bun-ffi-structs`
for Zig FFI). Anvil's constraint is Node.js 20+. Ink is production-ready,
Node.js native, and provides everything needed for onboarding TUI.

Key Ink primitives: `<Box>`, `<Text>`, `<Spinner>`, plus community packages
`ink-select-input`, `ink-text-input`, `ink-spinner`.
