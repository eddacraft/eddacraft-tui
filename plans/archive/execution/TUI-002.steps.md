## Context

Transform `anvil init` from a basic CLI command into a step-by-step TUI wizard.
The wizard guides users through mode selection, format choice, directory
configuration, and git hooks setup with preview.

Existing CLI behaviour must remain as fallback when TUI unavailable.

## Steps

### 1. Design wizard step flow

- **Checkpoint:** Step sequence defined: Mode → Format → Directory → Hooks →
  Summary
- **Checkpoint:** Each step has clear purpose and exit criteria
- **Files:** `cli/src/tui/commands/init/types.ts`

### 2. Create InitWizard container component

- **Checkpoint:** Manages wizard state and step transitions
- **Checkpoint:** Handles keyboard navigation (next, back, cancel)
- **Files:** `cli/src/tui/commands/init/InitWizard.tsx`

### 3. Implement ModeStep
