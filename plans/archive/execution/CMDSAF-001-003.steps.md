## Context

Core infrastructure for command safety validation. The system parses shell
commands, unwraps wrappers (bash -c, sudo, env), and matches against rules with
specificity ordering.

Reference: claude-code-safety-net's `shell.py` for wrapper patterns.

## Steps

### 1. Create rule type system (CMDSAF-001)

- **Checkpoint:** `CommandRule` interface with id, command, subcommand, flags,
  args, action, reason
- **Checkpoint:** `ParsedCommand` interface with raw, command, flags, args,
  unwrapped, wrapperChain
- **Checkpoint:** `CommandAnalysisResult` interface with parsed command and
  matched rule
- **Checkpoint:** `CommandSafetyConfig` interface for user configuration
- **Validate:** `nx build core` — passes
- **Files:** `core/src/gate/rules/types.ts`

### 2. Implement command parser (CMDSAF-002)

- **Checkpoint:** `CommandParser.parse(cmd)` tokenises shell commands
- **Checkpoint:** Parser unwraps `bash -c`, `sh -c`, `sudo`, `env`, `command`
  wrappers
- **Checkpoint:** Parser handles nested wrappers (depth limit 5)
- **Checkpoint:** Parser extracts interpreter one-liners (python -c, node -e)
- **Validate:** `nx test core --testNamePattern="CommandParser"` — 30+ test
  cases pass
- **Files:** `core/src/gate/parsers/command-parser.ts`,
  `core/src/gate/parsers/command-parser.test.ts`

### 3. Implement rule matcher (CMDSAF-003)

- **Checkpoint:** `RuleMatcher.findMatchingRule(parsed, rules)` returns most
  specific match
- **Checkpoint:** Specificity scoring: command (1) + subcommand (2) + flags
  (4) + args (8)
- **Checkpoint:** Flag matching supports required, forbidden, and dangerous
  flags
- **Checkpoint:** Combined short flags handled (-rf contains -r and -f)
- **Validate:** `nx test core --testNamePattern="RuleMatcher"` — passes
- **Files:** `core/src/gate/rules/rule-matcher.ts`,
  `core/src/gate/rules/rule-matcher.test.ts`

### 4. Export from index

- **Checkpoint:** Types exported from `core/src/gate/rules/index.ts`
- **Checkpoint:** Parser exported from `core/src/gate/parsers/index.ts`
- **Validate:** `pnpm typecheck` — passes
