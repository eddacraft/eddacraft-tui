# RUSTNX Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the `rust-nx-migration` APS module by shipping `cargo-hakari` workspace-hack (RUSTNX-008), the `cargo-deny` licence/advisory gate (RUSTNX-009), a `cargo-about`-generated `THIRD_PARTY_NOTICES.md`, and an `anvil licenses` CLI subcommand that prints that attribution at runtime.

**Architecture:** Three Rust tooling adoptions (hakari, deny, about) plus one CLI feature. Tooling configs live at repo root (`deny.toml`, `about.toml`, `about.hbs`, `.config/hakari.toml`). Generated attribution is committed to `crates/anvil-cli/resources/third-party-notices.md` and embedded in the anvil binary via `include_str!`. CI (`.github/workflows/rust.yml`) gets three new steps — hakari-verify, cargo-deny, about-diff — all behind the existing shared rust-cache.

**Tech Stack:** Rust (anvil-cli), clap, `cargo-hakari`, `cargo-deny`, `cargo-about`, handlebars (via cargo-about), GitHub Actions, Nx.

**Spec:** `plans/specs/2026-04-23-rustnx-completion-design.md`

```rust
//! `anvil licenses` — prints the anvil binary licence and the third-party
//! attribution generated by cargo-about at build time.

use std::fmt::Write as _;

use crate::GlobalArgs;

const NOTICES: &str = include_str!("../../resources/third-party-notices.md");

#[derive(Debug, Clone, Copy, clap::ValueEnum)]
pub enum Format {
    /// Paginated, human-readable output (default).
    Plain,
    /// Raw markdown source, suitable for piping or conversion.
    Markdown,
}

impl Default for Format {
    fn default() -> Self {
        Self::Plain
    }
}

#[derive(Debug, clap::Args)]
pub struct LicensesArgs {
    /// Output format.
    #[arg(long, value_enum, default_value_t = Format::Plain)]
    pub format: Format,
}

pub fn run(args: &LicensesArgs, _global: &GlobalArgs) -> anyhow::Result<()> {
    let output = render(args.format, supports_colour());
    print!("{output}");
    Ok(())
}

/// Produce the full `anvil licenses` output for the given format and colour
/// policy. Kept pure so unit tests can exercise every branch without
/// touching stdout or the `NO_COLOR` env var.
pub(crate) fn render(format: Format, use_colour: bool) -> String {
    match format {
        Format::Markdown => NOTICES.to_string(),
        Format::Plain => render_plain(use_colour),
    }
}

fn render_plain(use_colour: bool) -> String {
    let version = env!("CARGO_PKG_VERSION");
    let mut out = String::new();
    if use_colour {
        let _ = writeln!(out, "\x1b[1mAnvil {version}\x1b[0m");
    } else {
        let _ = writeln!(out, "Anvil {version}");
    }
    let _ = writeln!(out, "Copyright (C) 2026 EddaCraft. All rights reserved.");
    let _ = writeln!(out, "Licensed under LicenseRef-Proprietary.");
    let _ = writeln!(out);
    if use_colour {
        let _ = writeln!(out, "\x1b[1mThird-party dependencies:\x1b[0m");
    } else {
        let _ = writeln!(out, "Third-party dependencies:");
    }
    let _ = writeln!(out);
    out.push_str(NOTICES);
    out
}

/// Whether to emit bold ANSI sequences in the plain-format header.
///
/// Disabled when `NO_COLOR` is set (per https://no-color.org) or when the
/// output stream is not a TTY. Callers pass `use_colour` explicitly so the
/// pure `render` function stays testable.
fn supports_colour() -> bool {
    use std::io::IsTerminal as _;
    if std::env::var_os("NO_COLOR").is_some() {
        return false;
    }
    std::io::stdout().is_terminal()
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn plain_without_colour_contains_proprietary_header() {
        let out = render(Format::Plain, false);
        assert!(out.contains("Licensed under LicenseRef-Proprietary."));
        assert!(out.contains("Third-party dependencies:"));
        assert!(out.contains("Anvil "));
    }

    #[test]
    fn markdown_output_matches_embedded_file() {
        let out = render(Format::Markdown, false);
        assert_eq!(out, NOTICES);
    }

    #[test]
    fn plain_without_colour_has_no_ansi_sequences() {
        let out = render(Format::Plain, false);
        assert!(
            !out.contains('\x1b'),
            "expected no ANSI escape sequences when colour disabled"
        );
    }

    #[test]
    fn plain_with_colour_uses_bold_headers() {
        let out = render(Format::Plain, true);
        assert!(
            out.contains("\x1b[1mAnvil "),
            "expected bold Anvil header when colour enabled"
        );
        assert!(
            out.contains("\x1b[1mThird-party dependencies:"),
            "expected bold section header when colour enabled"
        );
    }
}
```
