## What ships

`v0.7.2-beta` is the second Boring-Week patch tag on the `v0.7.0-beta`
daemon-working slate. Unlike `v0.7.1-beta` (a focused activation-diagnostic
patch), this tag is a **full cut of `main`** — 164 commits since
`v0.7.1-beta`. The load-bearing customer change is the beta-feedback bug
cluster reported against `v0.7.1-beta`; the new policy-engine and
attribution-driver surfaces ride as freight and are explicitly **not** part
of the patch claim (POLENG is unfinished and ships experimental, which is why
this is a `0.7.2` patch and not a `0.8.0` minor).

**Patch-tag claim:** the save-time and tooling-honesty fixes below are live
on every shipped platform (Linux, macOS, Windows). The parent tag's
"Daemon-Working End-to-End Protection" claim is preserved verbatim; this tag
does not graduate the `v0.7.0-beta` sit-on claim, and cutting it does not
reset the Wave 5 Boring Week observation window.

### Load-bearing fixes (beta feedback vs v0.7.1-beta)

- **GH [#1913](https://github.com/eddacraft/anvil-001/issues/1913)** — bare
  `anvil watch` now runs code-quality checks (`anvil check --all`) on each
  save instead of driving only the architecture/dependency engine while the
  TUI read "100% pass" over an empty scan. `anvil watch --action none`
  restores the prior architecture-only behaviour.
- **GH [#1914](https://github.com/eddacraft/anvil-001/issues/1914)** —
  AP-003 / GS-001 no longer flag `any` / `!` inside comments and string
  literals; the scanner masks comments, strings, and regex literals before
  applying code-construct rules. Match offsets for genuine findings are
  unchanged.
- **GH [#1920](https://github.com/eddacraft/anvil-001/issues/1920)** —
  `anvil version` detects and warns when another `anvil` on `PATH` shadows the
  running binary (the Windows cargo-dist / Scoop stale-shim trap).
- **GH [#1921](https://github.com/eddacraft/anvil-001/issues/1921)** —
  `anvil auth refresh` surfaces the real 90-day refresh-token window instead
  of printing only the ~7-day access-token expiry.

### Freight (rides the tag, not load-bearing for the claim)

- **POLENG** — new `anvil policy` command group (`list` / `explain` / `diff` /
  `validate` / `test`) plus an **experimental** `anvil policy eval` Rego
  evaluation surface (PolicyInput v1, determinism contract, first-party
  builtins, Go OPA parity gate). Preview-quality; output shape may change.
- **ATTRIB** — bundled-binaries, Go, and Python attribution drivers feeding
  the ACKNOWLEDGEMENTS / supply-chain-attestation tooling.
- **MLP2-047** — pre-push hook subprocess smoke tests.
- **MLP2-051i** — `query_protection_claim` 500 ms timeout parity on the MCP
  path.

The remaining commits are docs / APS / spec maintenance per
`ENGINEERING-HISTORY.md` conventions.

## Process note

This tag was cut as a full `main` cut rather than a focused cherry-pick
patch, by operator decision, accepting that it broadens the shipped surface
(POLENG / ATTRIB) beyond the strict Boring-Week patch cadence the
`v0.7.1-beta` record describes. The patch **claim** is deliberately scoped to
the four load-bearing fixes; the freight surfaces are named experimental /
non-load-bearing so the claim stays verifiable.
