## Summary

The window where the **resident graph became an assistant-facing product**
(the ADR-075 deferral list) and the first run became worth sharing. GCTX
(14/14, [ADR-083](../decisions/083-gctx-mcp-delivery-target.md)) delivers
graph context to MCP/agent callers behind the PV-9 egress-privacy conditions;
GV2 closed out its consumer substrate (Done 21/21); warm-start persistence
landed twice over — DSV-030
([ADR-069](../decisions/069-graph-v2-persistence.md)) and the GBASE base+delta
store ([ADR-105](../decisions/105-shared-base-graph-persistence.md)) with
`ANVIL_PERSIST_GRAPH` now default-on. The default-on daemon became genuinely
useful without MCP: ACTMO registration UX (001..020) plus the headless
save-time driver (DSV-046..051,
[ADR-101](../decisions/101-headless-save-time-driver.md)). USAGE analytics
shipped in full (5/5).

The cut itself was conducted by **JOURNEY**
([release-user-journeys](../modules/release-user-journeys.aps.md)): WOW-005's
real-finding first win, ACTTUI-009/-010/-012 consent-first activation,
CIB-073/-183/-184/-190 terse repeat use and privacy-safe share evidence, the
DSV usefulness cut-line, the three-platform candidate rehearsal
(JOURNEY-005, [Linux record](../audits/2026-07-12-journey-005-linux-rehearsal.md)
+ cross matrix green), and the outcome-based final gate (JOURNEY-006: first
run 0.34 s to value, healthy repeat 0.026 s / 6 lines, one-next-action
compliance, byte-stable machine contracts, redaction green).

See the [Changelog](../../CHANGELOG.md) `## [0.9.0-beta]` section for the full
customer-facing entry list.

- **Publication recovery:** the release run's `host` job failed twice
  pre-publish at "Generate build provenance manifest" with
  `gh: Bad credentials (HTTP 401)` — `ANVIL_RELEASES_TOKEN` had expired
  (secret untouched since 2026-04-01). No partial state was created. The
  operator rotated the secret at 17:04 UTC and attempt 3 (17:06 UTC) reused
  the retained build artefacts and published cleanly end-to-end. Hardening
  intake: PR #3309 (`fix(release): harden publication recovery`).

  Unreleased draft left a metadata stub and missed draft entries; curation

  (inotify watcher saturation + live-daemon leakage into daemon-absence
  tests — hermetic runs and CI green; consolidated notes on #3305).

  at `0.9.0-beta`, commit `b02b2d9a9`), Scoop, and WinGet legs all green on
  attempt 3; `https://install.eddacraft.ai` serving (HTTP 200).
- **Cryptographic signing recovery:** the configured legacy minisign secret was
  a valid base64-wrapped raw binary key, and `rsign sign` also required explicit
  passwordless mode in non-interactive CI. PRs #3309, #3312, #3313, #3314,
  #3318, and #3319 hardened immutable run/tag binding, permissions, dispatch
  validation, parser-compatible comments, portable key normalisation, raw-key
  compatibility, and no-prompt signing. Run
  29207277673 then generated and self-verified all three `.minisig` assets,
  uploaded them privately, and mirrored byte-identical copies publicly.
  Independent local verification against the configured public key passed for
  both installers and the provenance manifest; all trusted comments bind the
