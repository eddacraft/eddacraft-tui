## Summary

A distribution and stability **patch** on the `v0.7.3-beta` slate. The headline
is the `ANVIL_HOME` / `--anvil-home` install-root override (DISTRIB-006), which
lets a development or candidate Anvil run beside a production install without
colliding on state. It also lands the RLB-007 watch-CPU stopgap (per-save checks
scope to the changed paths), Windows named-pipe daemon hardening, and a set of
CLI exit-code and output-selector correctness fixes. The save-time daemon arc
([ADR-061](../decisions/061-save-time-daemon-delta-validation.md)) was scoped in
this window but lands in `v0.8.0-beta`.
