# Release Plan: v0.3.0-beta

**Target:** v0.3.0-beta
**Cut from:** `dev` branch
**Previous release:** v0.2.1-beta (Edda Stack & Pattern Detection)
**Commits since last tag:** ~843 (non-merge)
**Date:** 2026-04-10 (planning), release TBD

## Release Theme

**Rust CLI & Native Engine** — Anvil is now a single native binary. The
Node.js CLI is archived. The Rust kernel provides structural graph analysis,
the TUI uses Ratatui, and distribution is via cargo-dist with Homebrew and
self-updater support.

## What Ships

### Rust CLI (RCLI, RCLI2)

Full native rewrite of the CLI in Rust using clap. 20 subcommands ported from
Node.js plus 4 Tier 2 additions.

| Area | Detail |
| ---- | ------ |
| Core workflow | check, watch, gate, gate-config, init, wizard, new, status, doctor, tutorial, welcome, audit |
| Auth & admin | auth login (device-code), admin approve |
| Policy & architecture | policy evaluate, architecture validate, drift (snapshot/compare/report/list), validate |
| Export & hooks | export (APS markdown, constraint formatters), hooks |
| Output modes | `--json` structured output across all commands, plain text, TUI |
| Credential migration | Legacy Node.js credential fallback with XDG auto-migration |
| Auth enforcement | Pre-action auth middleware for gate, watch, export |
| Watch enhancements | `--file`, `--action`, `--patterns`, `--exclude` flags |
| Secret scan | Improved robustness (RCLI-040) |

**APS modules:** RCLI (43/64 done — phases 1-7 complete, 8 partial, 9-11
proposed), RCLI2 (4/8 — check, validate, drift, gate-config ported)

### Rust Kernel (KERN)

Native core engine with file watching, parsing, graph analysis, and policy
evaluation.

| Area | Detail |
| ---- | ------ |
| Watcher | File watcher with debounce, backpressure, ignore patterns |
| Parser | Tree-sitter with AST cache, symbol extraction |
| Graph | Petgraph symbol graph, module-level dependency tracking, cycle detection, trust annotation, incremental updates (GraphDelta) |
| Policy | Architecture config from YAML, invariant evaluation (cross-layer, new-dep, public API, privilege), deduplication |
| Protocol | EngineEvent emitter, foreground watch mode, embedded mode |
| Infra | Dual-run harness, engine mode flag (Rust/Legacy/Dual), rayon parallel scanning |
| CI | Windows + macOS cross-compilation matrix (KERN-044) |

**APS module:** KERN (22/25 — phases 0-4 complete, phase 5 daemon draft)

## Release Process

Per the [release runbook](../../docs/runbooks/release-runbook.md):

1. **Version bumps** — non-Rust packages bumped in this PR
2. **CHANGELOG.md** — `[Unreleased]` converted to `[0.3.0-beta]` with
   comprehensive entries grouped by module
3. **Public docs sync** — reviewed against release checklist
4. **Cut `release/0.3.0-beta`** from dev
5. **Stabilise** — full test suite, cargo-dist build validation
6. **PR to main** → merge → tag `v0.3.0-beta`
7. **cargo-dist triggers** → builds 6 targets → GitHub Release on
   `eddacraft/anvil`
8. **Post-release** — merge `release/0.3.0-beta` back to dev
