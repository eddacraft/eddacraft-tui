## Theme

Minor on the v0.10 line after the published `v0.9.7-beta` first-session cut.
From a never-activated checkout through quiet daily recovery, anvil names what
is **proven** — closing receipt, live protection attach, worktree-pinned MCP —
and does not treat silence, missing MCP, or a configured-but-closed editor as
success. Minor scope (not a patch) because the window carries public feature
additions since `v0.9.7-beta`, not only honesty repairs.

JOURNEY-015 (pinned-main rehearsal) and JOURNEY-016 (simplification acceptance)
are **gates only**: they informed the claim and did not grant publication
authority. Claim freeze came from the operator-approved `RELEASE-PLAN.md` lock
(2026-09-11 wording; 2026-09-12 minor-scope confirmation).

## What shipped

Customer-facing summary is the public changelog section for `0.10.0-beta`
(Continuous journey honesty). Headline items:

- **Never-activated bare `anvil` is honest.** First use skips the licence wall
  when nothing is activated, and unattended `anvil start` no longer treats a
  missing MCP client as consent.
- **Protection status proves a client is actually attached.** A
  configured-but-closed editor is not a live attach; `anvil status` reports L4
  `on` only on a real pre-push hook plus a parseable config.
- **Quiet daily recovery.** A healthy bare `anvil` restores remembered
  integration coverage without a lecture, and daily ensure preserves explicit
  MCP launch choices rather than rewriting them during repair.
- **Truthful closing receipt after setup.** When selected MCP and save-time
  coverage land, the receipt names what is proven rather than what was offered.
- **MCP serve pins to the admitted Git worktree.** Package subdirectories,
  linked worktrees, and symlinks resolve to one canonical project shared with
  activation, status, graph, and validation.
- **Public guidance matches the simplified journey** (JSIMP-006).

Freight that rode the same tip (not the cut claim, still in the customer notes):
GATT graph attestation, secret-detection truth (SDT) fail-closed coverage,
GTAO gate-time catalogue, CONF/SETCON/FLAGCAT foundations, Windows park-and-swap
update, daemon ensure lock re-probe, and the CIB-211 pipe/ACL and CIB-215 /
CLAWREL credential-boundary repairs.

See [`CHANGELOG.md`](../../CHANGELOG.md) `## [0.10.0-beta]` and
`docs/public/anvil/releases/changelog.md`.
