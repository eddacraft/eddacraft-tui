## Summary

The first **minor** since `v0.7.0-beta`. Save-time governance moves off
per-save cold-spawned `check` and onto the persistent intercept daemon
validating deltas
([ADR-061](../decisions/061-save-time-daemon-delta-validation.md)), backed by
the GV2 resident hot-read index after the A→A′ swap (GV2-027,
[ADR-075](../decisions/075-v080-graph-product-scope.md)) — the durable fix for
the watch-CPU report
([#2156](https://github.com/eddacraft/anvil-001/issues/2156)). Daemon routing
is **default-on when a live daemon answers** (DSV-021, `ANVIL_WATCH_DAEMON=0`
opt-out). The release also ships Rust project analysis (RSTLAN), the live
gate-summary dashboard (TUIDASH), portable review capsules (`anvil capsule`,
[ADR-074](../decisions/074-review-capsule-v0-format.md)), the ungated
`anvil welcome` demo path
([ADR-080](../decisions/080-ungate-welcome-demo-surface.md)), and the
user-journey golden-path wave (UJ) required by the operator cut gate.

See the [Changelog](../../CHANGELOG.md) `## [0.8.0-beta]` section for the full
customer-facing entry list.
