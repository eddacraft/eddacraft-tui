## Summary

`v0.8.0-beta` is the first **minor** since `v0.7.0-beta`, and it earns the minor
bump on architecture, not surface area: it begins the move of save-time
governance off per-save cold-spawned `check` and onto the **persistent intercept
daemon validating deltas**, per **[ADR-061](../decisions/061-save-time-daemon-delta-validation.md)**
(Accepted 2026-06-01).

This is the real fix for the watch-CPU problem reported by Windows + concurrent-
agent beta testers. `v0.7.4-beta` shipped the **stopgap** (RLB-007: scope the
per-save check to changed paths, ~7 cores → ~0.08 cores); `v0.8.0-beta` ships the
**architecture** that makes that durable: a `validate_paths` daemon verb, a frozen
save-time wire contract, a per-workspace assurance state machine, and two
cooperating thread pools instead of single-pool oversubscription.

**Version framing (deliberate):** `scripts/release/assess.sh` already recommends
`v0.8.0-beta` (architecture-decision-changed signal from ADRs 060/061/062), and
the daemon save-time slice is a genuine minor — so unlike `v0.7.3`/`v0.7.4` we do
**not** override down to a patch.

**Timing:** there is **no calendar gate**. The Hotfix Iteration Plan's
six-week-post-tag minor-beta hold was **retired 2026-06-01** (authorised by Josh;
see the [release-cadence policy](../../docs/policies/release-cadence.md)) in
favour of continuous feature delivery toward an investor-ready solution.
`v0.8.0-beta` cuts **when the sub-phase A slice is ready and the release gates
are green** — not on a date. (`v0.7.3`/`v0.7.4` overrode down to patches under
the old rule; that rule no longer applies.)

## Headline

**ADR-061 sub-phase A — daemon-mediated save-time delta validation.** The
intercept daemon becomes the save-time validation authority. `anvil watch` and the
MCP pre-write path stop cold-spawning `check` and instead call a single
verdict-shaped verb over the existing daemon transport. Backed by an **interim
SymbolGraph cache** (rebuild-on-restart) — the Graph-V2 hot-read backing
(sub-phase A′) is explicitly **deferred** (see Deferred / Gated).

The frozen contract
([daemon save-time validation contract](../specs/2026-06-01-daemon-save-time-validation-contract.md)):

- `anvil/validate_paths` — `(workspace_root, paths: ChangeDescriptor[]) →
  (diagnostics, evaluated[], workspace_assurance, coverage)`. Delta validation,
  **not** whole-repo scan.
- `anvil/workspace_status` — `(workspace_root) → (state, reason, generation,
  last_full_scan)`. Per-workspace assurance:
  `clean | stale | pending | running | unavailable` (`unavailable` is the
  daemon-absent fallback, never `clean`).
- `anvil/request_full_scan` — `(workspace_root, priority) → (job_id, state)`.
- All ride the existing socket / named-pipe transport + JSON-RPC 2.0 + handshake.
  The wire is **verdict-shaped and frozen against backing change** — no graph
  representation crosses the wire, so sub-phase A′ swaps the backing under an
  unchanged contract.

## Sequencing (from ADR-061 §9)

1. **Phase 1 — shipped (v0.7.4):** RLB-007 per-save scope. The stopgap.
2. **Sub-phase A — this release:** `validate_paths` wire + watch/MCP re-point,
   interim SymbolGraph cache (rebuild-on-restart), two rayon pools. Gated by the
   correctness bar below.
3. **Sub-phase A′ — next:** GV2 hot-read slice swaps under the unchanged wire.
   **Blocked** on the GV2 boundary gate.
4. **Sub-phase B — later:** background scheduler + GV2-021 persistence (off by
   default; restores indexes, not verdicts).

## Cut criteria — the ADR-061 §8 correctness bar (hard blockers for sub-phase A)

1. **Exhaustive invalidation taxonomy** + mandatory inode-based change
   classification. `StaleReason` is frozen: `cross-file-resolution-needed |
   deleted | renamed | symlink-retarget | config-boundary-policy-edit |
   gitignore-scope-change | impact-set-overflow | warm-state-evicted |
   scan-timeout | daemon-absent | unknown-class`.
2. **Cross-path diagnostic parity** (order-normalised by path / rule_id /
   span_start) across watch+daemon, watch+fallback, MCP+daemon, MCP+fallback.
3. **`workspace_root` authorisation + read-safety** (`openat2` with
   `RESOLVE_NO_SYMLINKS`), plus operator allowlist-based workspace admission.
4. **Privacy line held:** persist structural identity only (symbol names,
   import/path edges, content hashes) — never raw source bodies, snippets, or
   secrets.
5. Standard release gates: full `Cross` matrix green (incl. Windows — see the
   home-resolution + tree-drop fixes that landed post-`v0.7.4`), the
   `.github/workflows/release-readiness.yml` workflow passing on the source SHA,
   `ACKNOWLEDGEMENTS` fresh.
