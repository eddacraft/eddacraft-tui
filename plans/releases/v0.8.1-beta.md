## Summary

Patch release cut one tag after `v0.8.0-beta` (which missed the GHCLIAUTH
merge by ~5 hours). Ships the **GitHub Device Authorisation Grant login**
([RFC 8628](https://www.rfc-editor.org/rfc/rfc8628),
[ADR-066](../decisions/066-github-device-flow-cli-auth.md)): the default
`anvil auth login` now works from a headless SSH/tmux session — the CLI shows
a short code and a `github.com/login/device` URL to open **on any device**,
with no email prompt and no website activation page. This closes the
un-completable-login bug introduced by #1779 (the old browser-confirm step
required an auth header the activation page could not send). Email OTP
(`--otp`) is retained as the no-GitHub fallback. The complete GHCLIAUTH module
(11/11) is in this tag: the server-side broker endpoints, `github_id` account
linking, the activation-page tombstone and rebuilt admin-invite flow, the dead
confirm-endpoint removal (owner-overridden sequencing), production
observability + the
[device-flow runbook](../../docs/runbooks/github-device-flow.md), and the
wiremock-backed headless E2E acceptance suite. Also rolls the eddacraft-tui
0.4.0 bump and a joi 18.x security dependency override that landed before the
cut.

See the [Changelog](../../CHANGELOG.md) `## [0.8.1-beta]` section for the full
customer-facing entry list.
