## Theme

Patch on the v0.11 line after the published `v0.11.0-beta` Windows-readiness
and inspect cut. The locked claim was **gate and inspect honesty** (primary
CIB-424): the commit gate names and scans the source types a React, Python, Go,
or shell repository actually commits. SETPREF Class A persist and CIB-414
git-parity landed on the same frozen SHA after prepare; they are tip freight,
not a second named window.

## What shipped

Customer-facing summary is the public changelog section for `0.11.1-beta`
(Gate and inspect honesty). Headline items:

- **Commit-gate secret detection covers React, Python, Go, and shell source.**
  A planted credential in `.tsx`, `.jsx`, `.py`, `.go`, or `.sh` fails
  `anvil gate --only-checks secret-detection`. Previously the gate only
  disclosed that those types were skipped.
- **Class A interface preferences persist.** Compact, timestamps, motion, and
  hints write to user-config through the settings service. Protection settings
  stay inspect-only.
- **Graph tools refuse a nested folder that is not itself a valid git checkout
  as a workspace root.** A planted empty `.git` directory is not enough to
  bypass this. A nested folder that is itself a complete git repository can
  still be used as a workspace root.
- **kindling runtime logs live under `.anvil/`, not in tracked `anvil/`.**
- **Consumer CLI output no longer names internal planning IDs.**
- **The kindling daemon does not auto-spawn when no `kindling` binary is on
  PATH.**
- **The public site waitlist sits in the hero.**

See [`CHANGELOG.md`](../../CHANGELOG.md) `## [0.11.1-beta]` and
`docs/public/anvil/releases/changelog.md`.
